# 员工端小程序

## 运行步骤

1. 启动后端：`cd hr-saas && npm run start:dev`（默认 3000 端口）
2. 用微信开发者工具打开 `hr-saas/miniprogram/`
3. 在「详情 → 本地设置」勾选「不校验合法域名」
4. 登录页输入工号（如 `E001`）与任意密码（MVP 认证仅按工号查找员工）

## 页面

- **职业通道**：软件研发序列 P1–P5 通道 + 各级标准摘要
- **我的认证**：发起认证申请、上传举证材料、查看状态机节点
- **在线考试**：查看当前待参加考试（MVP 提示联系 HR 发布试卷）
- **我的 IDP**：查看 IDP 目标、关键行为计划、复盘结论

## 角色边界

- 员工仅可见本人数据（`X-Employee-Id` 头自动携带当前登录员工）
- 「AI 生成·待审核」内容（试卷、IDP 草稿）在管理端审核通过前对员工不可见
