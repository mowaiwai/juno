# 06 差距分析与 IDP

Status: done
Blocked by: 05

## 任务

实现 MVP 闭环的收尾：标准 × 画像比对产出五类差距，确定性动作路由，派生 IDP 并跟踪。

## 范围

1. `POST /api/hr/match/analyze`：对部门/批次执行 标准 × 现状比对，产出 `gap_analysis`（五类 gap_type + 差距明细 + 严重度）
2. 动作路由（确定性规则，不进 LLM）：业绩→绩效改进、履职→过程监督、能力→行为改善、团队贡献→团队任务、知识→学习（ADR-0004：规则一期编码在流程节点中）
3. IDP：`POST/GET /api/hr/idp`，季度周期；AI 可依据差距生成 IDP 草稿（A 类，调 LLM 前脱敏），人工确认生效；含目标能力 + 关键行为计划 + 复盘结论
4. 管理端差距看板（按人/按维度清单）与 IDP 管理页

## 验收

- 对有认证结论的虚拟员工执行分析：产出差距清单，每类差距的 suggest_action 符合路由规则
- AI 生成 IDP 草稿带「待审核」标记，脱敏后调用（请求中无姓名/工号），确认后生效
- IDP 复盘结论可回写，留痕
