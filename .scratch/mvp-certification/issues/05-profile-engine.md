# 05 画像引擎最小版

Status: done
Blocked by: 01, 03

## 任务

实现画像引擎最小版（ADR-0005）：绩效导入 + 认证结果 → 七维快照，版本化、可追溯。

## 范围

1. 汇聚逻辑：两路触发——绩效导入完成 / 认证生效——生成或更新 `profile_snapshot`
2. 七维 dimension_data（JSON）：基本条件/业绩/团队贡献/职责履行/知识技能/能力素质/绩效
   - MVP 数据源：基本条件（员工主数据）、绩效（perf_result）、知识技能（考试记录）、职责履行与能力素质（认证评审结论）、业绩（perf_result 汇总）
   - 「潜力」维度留空（MVP 无测评问卷）
3. 版本化：同周期版本号唯一，历史快照可查询
4. 接口：`GET /api/hr/profile/{employee_id}`（含版本列表）
5. 管理端画像页：七维展示 + 版本切换；按角色掩码（员工仅本人）

## 验收

- 绩效导入后目标序列全员生成首版画像
- 认证生效后画像 current_grade 与相关维度自动更新，产生新版本
- 员工角色仅可见本人画像；经理可见所辖子树

## 参考

- PRD「核心实体-人才画像」、DDL profile_snapshot
- CONTEXT.md「人才画像」；ADR-0005（最小版范围）

数据范围按组织树推导是 RBAC 完整版的能力，MVP 只做「本人/所辖子树/全公司」三档判断，完整三重校验后置。
