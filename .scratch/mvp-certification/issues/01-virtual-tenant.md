# 01 虚拟租户主数据构建

Status: done
Blocked by: 无

## 任务

构建虚拟租户的全部主数据与样本数据，作为 MVP 开发和验收的数据底座。

## 范围

1. 脚手架：按 ADR-0007 新建代码库（NestJS + MySQL + React 管理端），建库建表（spec.md 表清单，全部带 tenant_id）
2. 虚拟租户：虚构 1 家企业（行业不限，建议通用科技/制造企业），含：
   - 部门树（≥3 层，≥8 个部门）
   - 岗位（选定 1 个目标序列如「软件研发」，P1–P5；另设 2–3 个非目标序列岗位作背景数据）
   - 职级通道（职族 P/T/M，职级顺序、角色定义、薪级带宽可留空——MVP 无薪酬模块）
   - 10–50 名虚拟员工（分布在目标序列各职级，含部门经理归属）
3. 绩效样本：近 2 年 S/A/B/C/D 分布的 perf_result 数据（覆盖「近两年至少一个 A」「近一年 B 以上」等硬校验正例与反例）
4. CSV 导入模板与 `/api/hr/perf/import` 接口

## 验收

- 目标序列任意员工可查出：所属部门树路径、岗位、职级、近两年绩效
- 绩效导入接口对正例/反例样本均正确落库并留痕
- 数据全带 tenant_id，第二租户插入后互不可见
