# 五大人才管理体系作为产品蓝图与路线图

_Status: accepted, 2026-10-04。_

## 背景

用户提供的《人才管理框架》（飞书 wiki，含一张思维导图式架构图，本地留档 talent-framework.jpg，工作区临时产物不入库）把企业人才管理拆成五大体系、共 27 个模块，并用"价值创造 → 价值评价 → 价值分配"构成闭环。Juno 已建成的功能（任职资格标准、认证、七维画像、盘点、继任梯队、IDP、差距、招聘管道雏形、考试）需要一把统一的尺子审视覆盖度并决定建设顺序。

## 决策

### 1. 五体系作为产品全景蓝图（North-Star）

PRD 的模块地图、权限点目录分组、COE 视角导航统一按五体系组织：

1. **人才标准体系（基础层）**：战略规划 → 组织架构与组织诊断 → 部门职责与岗位设置 → 岗位职责与人才画像 → 岗位称重与价值评估 → 职级职等与职类管理 → 职业通道与序列管理 → 任职资格与晋升管理。
2. **人才选聘体系（入口层）**：业务规划与人才规划 → 人才甄选与人才测评 → 人才融合与雇主品牌 → 员工关系与风险管理。
3. **人才评价体系（价值创造与评价）**：战略解码与组织绩效 → 目标分解与标准建立 → 干部绩效与个人绩效 → 绩效辅导与过程管理 → 结果应用与绩效改进。
4. **人才激励体系（价值分配）**：等级工资 → 奖金方案 → 津贴补贴与福利 → 短中长期与股权 → 荣誉表彰；原则为"以岗定级、以级定标、以能定薪、以绩定奖"。
5. **人才发展体系（成长层）**：干部标准与干部管理 → 人才盘点与岗位盘点 → 人才梯队与继任计划 → 经验萃取与课程开发 → 学习地图与人才发展；以"岗位履职要求"和"任职资格标准"为双轴。

五体系与 COE 五板块的对应：招聘运营↔选聘，绩效管理↔评价，薪酬激励↔激励，组织与人才发展↔标准+发展，干部管理↔发展体系干部线。

### 2. 框架的产品表达边界

- 框架是**方法论与信息架构蓝图**，本轮不做客户可见的"全景页"产品功能（记入 P2）。
- 战略层（战略规划、战略解码与组织绩效）**不建独立功能模块**：战略只作为组织诊断、绩效模块的上下文输入。
- 导航双轨：COE 视角一级导航按五体系分组（菜单项仍由激活角色权限点动态过滤）；HRBP/部门领导/员工视角保持任务式导航（工作台/我的团队/我的认证/我的发展），不向业务角色暴露方法论架构。

### 3. 现状盘点（2026-10-04）

- **已建成**：任职资格标准库与认证主链、七维人才画像（版本化快照）、人才盘点（批次状态机/九宫格/校准）、核心岗位与继任梯队、IDP、差距分析、组织诊断、职级层级框架与租户映射、招聘管道（需求/候选人/面试/AI 题库）、考试（AI 组卷）、Cockpit QA。
- **雏形/静态**：部门树与岗位编制为硬编码静态数据、职业通道与薪级带宽静态、绩效仅 perf_grade 外部导入、课程/学习地图/薪酬等仅有原型 mock 页。
- **空白**：岗位价值评估、人才测评、onboarding 融合、员工关系风险、绩效全过程（目标/辅导/考评内生）、激励五模块、干部标准、岗位盘点、课程开发。

### 4. 路线图

- **P0（本轮，权限重构顺带）**：部门树实体化、岗位/通道/薪级租户可维护、员工定薪最小字段——标准体系基础设施扶正，随 ADR-0014 落地。
- **P1（下一仗：绩效内生 + 组织/干部侧补齐）**：目标分解 → 个人与干部绩效考评 → 绩效辅导记录 → 结果内生回写（盘点业绩轴、IDP、未来薪酬联动从系统取数，停止只靠 CSV 导入）；同期立**岗位盘点**（组织侧：编制 vs 在岗、关键岗位覆盖、组织健康，与人侧九宫格并列）与**干部标准**（干部池与领导力要求，配套干部管理角色）。
- **P2（接通价值分配与入口）**：薪酬管理（等级工资/调薪/奖金方案，落地以能定薪、以绩定奖）、选聘深化（人才规划联动编制、onboarding 融合、员工关系/风险）、产品内五体系全景页。
- **P3（远期完善）**：战略解码/组织绩效、人才测评、课程开发/学习地图、津贴福利/股权/荣誉表彰、岗位价值评估。

选择 P1 先做绩效内生的理由：绩效是闭环枢纽——盘点业绩轴、IDP 差距、以绩定奖三处目前都缺内生数据源，它一旦建成，价值循环才真正闭合。

## 后果

- 此后新增模块在 PRD 中必须归入五体系之一并标注 P0–P3 状态；模块地图、权限点、COE 导航三处分组保持同一套词汇。
- 术语裁决（岗位画像 vs 人才画像、职等=六层 Level 的对外解释、岗位价值评估、发展双轴不另建实体、岗位盘点正名）见 CONTEXT.md。
